# Продажи ЖК, март–сентябрь 2026

Проект по курсу «Визуализация», вариант 1. Аналитический дашборд с кросс-фильтрацией: схема корпусов (основной график), сделки по неделям, срезы по комнатности, менеджерам и виду из окна.

Открыть: `index.html` (d3 v7 с cdnjs, данные в `data.js`, собираются из xlsx скриптом `build_data.py`).
